# AdLab Simulator 2026

Навчальний симулятор рекламного кабінету для таргетологів — від Beginner до Advanced Performance Marketer.
Користувач сам створює кампанії (Campaign → Ad Set → Ad), налаштовує аудиторії, бюджети, плейсменти й креативи, публікує, проходить перевірку налаштувань і оголошень, запускає детерміновану симуляцію доставки та аналізує результати.

> AdLab — незалежний навчальний продукт, **не** пов'язаний з Meta Platforms, Inc. Він не підключається до справжніх рекламних акаунтів. Усі витрати, покази, аукціони й конверсії — віртуальні навчальні дані, а не прогноз реальної ефективності.

## Швидкий старт

```bash
npm install          # .npmrc містить legacy-peer-deps=true (потрібно для vitest 4)
npm run dev          # http://localhost:3000
```

Прогрес зберігається в `localStorage` браузера. API-ключі не потрібні.

### Перевірки

```bash
npm run typecheck    # TypeScript
npm run lint         # ESLint (next lint)
npm test             # 93 unit + інтеграційні тести (Vitest)
npm run build        # production-збірка
PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers npm run test:e2e   # 14 e2e-тестів (потрібна збірка)
```

E2E-тести запускають `next start` на порту 3100. Якщо браузери Playwright встановлено в іншому місці, задайте `PLAYWRIGHT_BROWSERS_PATH` або `PW_CHROMIUM_PATH`.

### Опційно: Supabase

1. Скопіюйте `.env.example` у `.env.local` і заповніть `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
2. Застосуйте `supabase/migrations/0001_app_snapshots.sql` (таблиця знімків прогресу з RLS).
3. У Settings з'явиться вхід через magic link і кнопки «Зберегти в хмару» / «Завантажити з хмари».

Інтеграцію написано за документацією `@supabase/supabase-js`, але з живим проєктом Supabase її не перевіряли. Без змінних середовища застосунок працює в повністю локальному режимі.

## Відомі обмеження

- Модель — навчальне спрощення: числові параметри (CPM за країнами, базові CTR/CVR, частки інвентарю) є припущеннями, а не даними Meta.
- Поріг «суттєвої» зміни бюджету (20%) — припущення: Meta не публікує точного значення.
- Відео не зберігається повністю: зберігаються постер-кадр і тривалість.
- Оцінка текстової аргументації — евристика (довжина + ключові поняття), а не розуміння тексту.
- Охоплення між наборами сумується без урахування перетину аудиторій.
